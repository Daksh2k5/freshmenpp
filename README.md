About

Freshmen++ helps students look up professor reviews before FFCS (Fully Flexible Credit System) registration, so you know what you're signing up for before it's too late to change your slot.

This project is inspired by and built on top of Freshmen23, an earlier open-source effort. In the original project's source, several professor reviews couldn't be searched due to indexing errors, and new reviews weren't being added. Rather than patch the original repo, this project was built independently — fixing the search and indexing issues, adding a dark theme, and making it easier to keep reviews up to date, while also allowing custom forms for submitting responses.

You're encouraged to check out Freshmen23 for the original experience and to support the original creators.
